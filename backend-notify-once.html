두 번 눌러도 알림은 한 번만

버튼을 두 번 누르거나 응답이 늦어 요청이 다시 가도, 서버가 같은 요청 ID를 확인해 알림을 한 번만 만듭니다.

가상 서버 상태

받은 요청 0건 , 만든 알림 0건

  • 아직 요청이 없습니다.

동작 방식

  • 버튼을 누를 때마다 클라이언트가 요청 ID를 한 번 만듭니다.
  • 중복 클릭과 재시도는 같은 요청 ID를 그대로 보냅니다.
  • 서버는 처리한 요청 ID를 저장해 두고, 같은 ID가 오면 알림을 만들지 않습니다.

요청 ID가 없으면 서버는 두 요청을 서로 다른 요청으로 보고 알림을 두 번 만듭니다.
